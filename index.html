What I do

SEO from the code to the customer.

Three areas of work that move a site from being found to being chosen.

Technical SEO

I find and fix what stops Google from reading a site: crawl and indexing problems, slow pages, Core Web Vitals, redirects, sitemaps, robots.txt, and schema markup. More about technical SEO

Keywords and content

I map keywords to what people are really searching for, then plan content in topic clusters with strong internal links. I've optimized 1,000+ product and collection pages. More about eCommerce SEO

Links and local SEO

I build backlinks through outreach and competitor research, and set up Google Business Profiles for local businesses like gyms and schools. More about local SEO

How I run an engagement

  1. Audit

    Crawl the site, check indexing and Core Web Vitals, and read Search Console to find where traffic is being lost.

  2. Prioritize

    Rank every fix by its likely effect on clicks and revenue, so the first weeks go to what moves the numbers.

  3. Execute

    Technical fixes, keyword mapping, page optimization, internal links, and outreach for backlinks.

  4. Measure

    Report clicks, impressions, position, and revenue from the client's own data, then plan the next cycle.
